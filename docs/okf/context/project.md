# Project Context

## Purpose
A simple public web application that lets users search for a city and view its current weather conditions and a 5-day weather forecast using an external weather service.

## Users
- Casual end users who want to check the weather.

## Workflows
- Open the homepage.
- Enter a city name into the search field.
- Search matching locations through an external geocoding API.
- If multiple locations match, select the correct city.
- Fetch current weather conditions and a 5-day forecast for the selected city's coordinates.
- Display temperature, weather conditions, humidity, wind speed, weather icons, and the last updated time.
- Show daily minimum and maximum temperatures and weather conditions in forecast cards.
- Search for another city and replace the previously displayed results.
